## À propos

**CAP IA** est un projet porté par l’Université de Bordeaux, lauréat de l’AMI « Compétences et Métiers d’Avenir » de France 2030. Il vise à renforcer la formation en intelligence artificielle en Nouvelle-Aquitaine et à favoriser les liens entre formation, recherche et entreprises.

Cette organisation GitHub rassemble des **applications développés dans le cadre de CAP IA**.

Plusieurs dépôts proposent des **applications interactives, des dashboards ou des API**, souvent **déployés sur Render** et accessibles directement depuis le README du projet.

---

## Dépôts

Les dépôts de cette organisation présentent différents projets autour de la **data science, de l’intelligence artificielle, de la visualisation de données et du MLOps**.

Selon le projet, vous pouvez y retrouver :

- des dashboards interactifs
- des API de prédiction
- des démonstrateurs IA
- des pipelines MLOps
- des applications déployées accessibles en ligne

Lorsqu’une application est déployée, le lien vers la démonstration est indiqué directement dans le README du dépôt concerné.
